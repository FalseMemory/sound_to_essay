## 二、各任务交付内容

### A1 录音转写解耦
- 录音落盘后先登记"记忆 + 音频资产 + 待转写任务"，再执行 STT；转写失败/崩溃不留孤儿音频。
- 转写任务状态（pending/processing/success/failed）持久化在 `transcription_tasks`，重启后仍可重试。
- 启动时自动复位遗留 `processing` 为 `pending`，抢救残留分片为 WAV 并登记。

### A2 版本与来源保护
- 原始转写（`raw_transcription`）不可删除；前端显示「受保护」。
- 恢复历史版本只切 `is_current` 指针，不复制内容（记忆版本 + 章节草稿都适用）。
- 新增 `chapter_draft_sources` 表 + `chapter_drafts.requirement` 列，AI 生成时记录实际使用的记忆/文本版本与写作要求；旧草稿来源读生成时记录，不用当前关联列表。
- 被草稿引用的文本版本不可删；删除当前草稿自动接管（提升剩余最新为当前）。

### A3 编辑保护与完整备份
- 未保存保护：`loadDetail` 存原始快照，`hasUnsavedChanges` 驱动 `beforeunload`（关/刷新提示）。
- 筛选状态分离：`browseFilter`（人物/地点/标签）独立于 `selectedId`（记忆）/`selectedChapterId`（章节）。
- 完整备份 `.svbak`：零依赖自实现（magic + manifest + 文件条目 + 逐文件 SHA-256），数据库走 SQLite 在线备份 API（一致性快照）。
- 恢复先校验后替换：校验 magic/manifest/格式版本/每文件 SHA-256/数据库可打开；恢复前备份当前数据库到"后悔药"路径再替换。
- 章节软删保留 `chapter_memories` 关联。

### B1 导入 iPhone 录音
- 资料库「章节」模式新增「导入音频」入口，多选 wav/m4a/aac/mp3/ogg/flac/aiff。
- 探测（ffprobe→soundfile→mutagen→文件头）+ 转码（ffmpeg→soundfile）为 16-bit PCM WAV 派生文件。
- 复制源文件到应用音频目录（不依赖源文件），记录 `original_filename`/`source_format`/`file_checksum`。
- 复用 A1 `register_recording`：记忆 + 音频资产 + 待转写任务；按 checksum 去重；损坏文件报错不留伪成功。

### B2 定义素材包格式
- 协议文档 `docs/素材包协议.md` v1：容器（推荐 ZIP/允许等价）、manifest、records（稳定 recordId + revision、模糊事件时间独立保存）、音频条目、安全约束、导入语义、版本演进。
- 明确区分"传输素材包" vs "完整桌面备份"。
- 测试样例 `tools/pack_samples/`：合法包 / SHA 篡改 / 版本 999 / 缺失音频，生成与校验脚本均通过。

### B3 桌面素材包导入
- 「导入素材包」入口：选包 → 预览（记录/音频/重复/冲突/缺失）→ 导入。
- 按 `recordId` 去重（`memories.source_id`/`source_revision`）；revision 大者更新；冲突保留双方（标题加"冲突副本"）；不传播删除。
- 缺失音频不伪装完整导入，统计并提示。
- 首版支持 `.svpack`（自实现容器，与 `.svbak` 同构）；ZIP 识别入口已留，待能链接的环境补全。

## 四、已知限制（汇总）

1. **本机无 C 链接器**：无法执行 `cargo test`/`cargo build`；无法引入 ZIP 库（故用 `.svpack`/`.svbak` 自实现容器）。
2. **解码依赖未内置**：B1 探测/转码依赖用户 Python 环境的 ffprobe/ffmpeg/soundfile/mutagen；发布版需明确标注并提供安装检查（未做）。
3. **应用内切换视图无阻断式未保存弹窗**：A3 只做了 `beforeunload`（关/刷新提示）。
4. **`.svbak`/`.svpack` 非通用格式**：仅本应用可恢复/导入；ZIP 支持待补。
5. **历史草稿无来源**：A2 之前生成的草稿无法追溯当时输入。
6. **录制时间留空**：M4A 录制时间不可靠，B1 导入时留空。
