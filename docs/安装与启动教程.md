# 安装与启动教程（声文 Voice to Essay）

> 本文是「从零到跑起来」的操作手册。想直接开干，看 **方式一：一键启动**；想理解每一步在做什么，看 **方式二：手动安装**。
> 更偏架构/配置的细节参见仓库根目录 `README.md`（环境准备与安装 / 运行方式 / 配置说明等章节）。

---

## 0. 它是什么，怎么跑

「声文」是一个 **Tauri 2 + React + Rust + Python(faster-whisper)** 的 Windows 桌面应用：

- **Rust 后端**：提供所有数据读写、录音、转写调度、AI 调用等能力（Tauri 命令）。
- **React 前端**：Vite 开发服务器，负责界面。
- **Python STT**：`python_stt/transcribe.py`，在「转写」时由 Rust 通过虚拟环境里的解释器调用，**不是**常驻服务，不需要你手动起一个 Python 进程。

所以「启动」本质上就是一条命令：

```bash
npm run tauri dev
```

它会同时拉起前端（Vite）和后端（Rust 编译 + 窗口）。但在此之前，需要把三样东西备齐：**Node 依赖、Python 虚拟环境里的 faster-whisper、以及 Rust 工具链**。下面的脚本把这些都自动化了。

## 1. 方式一：一键启动（推荐）

仓库根目录提供两个统一启动脚本，会**自动检查环境、安装缺失依赖、再拉起应用**，可反复运行（幂等，不会重复装）：

| 系统 / 终端 | 脚本 | 用法 |
|---|---|---|
| Windows（PowerShell / 文件管理器） | `start.ps1` | 见下方 |
| Git Bash / WSL / Linux / macOS | `start.sh` | `./start.sh` |

### Windows 运行 `start.ps1`

最省事的方式（适用于已装 PowerShell 的 Windows 10/11）：

1. 打开文件资源管理器，进入项目根目录 `F:\AI\sound_to_essay`。
2. 在地址栏输入 `powershell` 并回车，打开终端。
3. 执行：

   ```powershell
   .\start.ps1
   ```

如果系统提示「无法加载，因为在此系统上禁止运行脚本」（执行策略限制），用下面这条绕过：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

> 脚本会自动：检查 `node` / `cargo` / `python` → 创建或复用 `python_stt/.venv` 并装好 `faster-whisper` → 确保 `node_modules` → 执行 `npm run tauri dev`。
> 首次运行会编译 Rust，可能要等几分钟，之后窗口会自动弹出。

### Git Bash / WSL / Linux / macOS 运行 `start.sh`

```bash
cd /path/to/sound_to_essay
./start.sh
```

（Windows 上的 Git Bash 同样可用，脚本会自动识别 `.venv/Scripts/python.exe`。）

## 2. 方式二：手动安装与启动

适合想看清每一步、或脚本在你的环境里报错的场景。

### 2.1 前置环境

| 软件 | 版本要求 | 用途 | 安装 |
|---|---|---|---|
| Node.js | 18+（建议 LTS） | 前端构建 | https://nodejs.org ，安装时勾选 *Add to PATH* |
| Python | 3.10+ | STT 转写 | https://www.python.org ，安装时勾选 *Add to PATH* |
| Rust | 1.77.2+（**MSVC** 工具链） | 后端编译 | https://rustup.rs |
| Visual Studio Build Tools 2022 | 含「C++ 桌面开发」工作负载 | 提供 MSVC 编译器 | `winget install Microsoft.VisualStudio.2022.BuildTools` 后勾选 C++ 桌面开发 |
| WebView2 运行时 | 系统级 | Tauri 窗口内核 | Win10/11 一般已预装；缺失时从微软官网装「Evergreen Bootstrapper」 |
| Git | 任意 | 拉取代码 | https://git-scm.com |

安装完 Rust 后确认用的是 MSVC 工具链（Windows 必须）：

```powershell
rustup default stable-msvc
```

> 选 Rust 时务必是 **MSVC**（`stable-msvc`），不是 GNU。GNU 工具链在 Windows 上经常因链接器/WebView2 头文件缺失而编译失败。

### 2.2 安装 Python 依赖（关键，容易漏）

`npm run tauri dev` **不会**自动安装 Python 依赖。必须先把 `faster-whisper` 装进虚拟环境：

```powershell
cd F:\AI\sound_to_essay\python_stt
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> 仓库里通常已带 `python_stt/.venv`（含 faster-whisper 1.2.x）。若你换机器或删除过它，按上面重建即可。
> 注意：`requirements.txt` 只声明了 `faster-whisper`，没有锁定 `opencc`；繁→简转换在 `transcribe.py` 里做了降级（内置映射表），即使没装 `opencc` 也能跑，只是覆盖面略小。

### 2.3 安装前端依赖

```powershell
cd F:\AI\sound_to_essay
npm install
```

### 2.4 启动

```powershell
cd F:\AI\sound_to_essay
npm run tauri dev
```

首次会自动：编译 Rust 后端 → 启动 Vite 开发服务器 → 弹出桌面窗口。应用启动后自动加载上次打开的项目，无历史项目则显示空白工作区。

## 3. 首次运行：下载 Whisper 模型

转写需要本地 faster-whisper 模型。应用**不会**在录音时自动下载，请先在应用内「设置」页：

1. 选择一个模型尺寸（如 `tiny` / `base` / `medium`，越小越快、越大越准）。
2. 选择/确认模型保存目录（默认 `models/<模型名>/`）。
3. 点击下载，等待进度完成。

也可以设置环境变量指向已有模型：

- `WHISPER_MODEL_DIR`：指向模型根目录，或某个完整的 faster-whisper 模型目录。
- `WHISPER_DEVICE` / `WHISPER_COMPUTE_TYPE`：覆盖默认 `cpu` / `int8`（如有 GPU 可改）。

> 国内网络：脚本/程序已默认走 `HF_ENDPOINT=https://hf-mirror.com` 镜像。若下载极慢，可手动从 HuggingFace 镜像站下载对应 `Systran/faster-whisper-<size>` 的 CTranslate2 模型，放到 `WHISPER_MODEL_DIR` 下。

## 4. 常见问题排查

| 现象 | 原因 / 解决 |
|---|---|
| `无法加载文件 …start.ps1，因为在此系统上禁止运行脚本` | PowerShell 执行策略限制。用 `powershell -ExecutionPolicy Bypass -File .\start.ps1` 运行。 |
| `error: linker 'link.exe' not found` 或类似 MSVC 报错 | 没装 VS Build Tools 的「C++ 桌面开发」，或 Rust 用的是 GNU 工具链。装好 C++ 桌面开发后执行 `rustup default stable-msvc`。 |
| 窗口起不来 / 报 WebView2 相关错误 | 系统缺 WebView2 运行时。安装微软「WebView2 Evergreen Bootstrapper」。 |
| `找不到 transcribe.py` 或 `找不到 Python 环境` | Python 虚拟环境缺失或路径不对。重跑 `start.ps1`/`start.sh`，或按 §2.2 手动建 venv。 |
| 转写时报「Whisper 模型不可用 / 无法下载」 | 未在设置页下载模型，或网络被墙。先下载模型；或配置 `WHISPER_MODEL_DIR` 指向已有模型。 |
| 转写结果出现繁体字 | `opencc` 未安装，已走内置降级映射。影响不大；如需完整繁→简，在 venv 里 `pip install opencc-python-reimplemented`。 |
| `npm` / `cargo` 不在命令里 | 对应软件没装，或安装时没勾 *Add to PATH*。重装并确认 PATH。 |
| 首次编译卡很久 | 正常。Rust 首次 `cargo build` 要拉取并编译大量 crate，几分钟到十几分钟，之后有缓存会快很多。 |

## 5. 生产构建 / 打包

开发验证无误后，可打包成安装程序：

```powershell
cd F:\AI\sound_to_essay
npm run tauri build
```

产物位于 `src-tauri/target/release/bundle/`，包含 `.exe`（NSIS 安装包）、`.msi`、以及便携版可执行文件。

> 构建同样需要上面的 MSVC 工具链与 WebView2。Python STT 目录会作为资源（`resources/python_stt`）一起打进包里。

## 6. 目录结构速览

```
sound_to_essay/
├─ start.ps1 / start.sh      # 本文的统一启动脚本
├─ package.json              # 前端脚本（dev/build/tauri…）
├─ src/                      # React 前端
├─ src-tauri/                # Rust 后端（Tauri 命令、录音、STT 调度）
│  ├─ src/lib.rs             # 命令注册（generate_handler!）
│  ├─ src/stt.rs             # 调用 python_stt/transcribe.py
│  └─ tauri.conf.json        # 构建/窗口/资源配置
├─ python_stt/               # Python STT（faster-whisper）
│  ├─ .venv/                 # 虚拟环境（含 faster-whisper）
│  ├─ transcribe.py
│  └─ requirements.txt
├─ models/                   # Whisper 模型（应用内下载）
├─ sounds/                   # 录音 WAV（原始素材，不自动删）
├─ data/                     # oral_history.sqlite3 资料库
└─ tools/codegen_archive/    # 历史代码生成脚本归档（不参与构建）
```

## 7. 一句话总结

> **最省事**：双击/在 PowerShell 跑 `start.ps1`（或 Git Bash 跑 `./start.sh`），等窗口弹出，去设置页下个 Whisper 模型，就能开始口述了。
> **想自己掌控**：按 §2 手动装 Python venv + npm，再 `npm run tauri dev`。
