# 安装与启动（声文 Voice to Essay）

> 本文是「从零到跑起来」的操作手册。想直接开干看 **§1 一键启动**；想理解每一步在做什么看 **§2 手动安装**。
> 架构与配置细节另见仓库根目录 `README.md`。
>
> 本文由原《安装与启动教程》与《启动说明》合并去重而成，并修正了其中的过时信息；两份原文已归档至 `archive/`。

---

## 0. 它是什么，怎么跑

「声文」是一个 **Tauri 2 + React + Rust + Python(faster-whisper)** 的应用，含**桌面端**与**手机网页记录端**：

- **Rust 后端**：数据读写、录音、转写调度、AI 调用（Tauri 命令）。
- **React 前端**：Vite 开发服务器，负责界面。
- **Python STT**：`python_stt/transcribe.py`，转写时由 Rust 调用，**不是常驻服务**，无需手动起 Python 进程。

所以「启动」本质上就是一条命令：

```bash
npm run tauri dev
```

它会同时拉起前端（Vite）与后端（Rust 编译 + 桌面窗口）。在此之前需要备齐三样：**Node 依赖、Python 虚拟环境里的 faster-whisper、Rust 工具链**。下面的脚本把这些自动化了。

## 1. 方式一：一键启动（推荐）

| 系统 / 终端 | 脚本 | 用法 |
|---|---|---|
| Windows | **双击 `启动声文.bat`**（最省事）或 `start.ps1` | 见下 |
| Git Bash / WSL / Linux / macOS | `start.sh` | `./start.sh` |

在项目根目录打开 PowerShell 后：

```powershell
.\start.ps1
```

若提示「无法加载，因为在此系统上禁止运行脚本」（执行策略限制）：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

或**直接双击 `启动声文.bat`**——`.bat` 不受 PowerShell 执行策略限制。

> 脚本会自动：检查 `node` / `cargo` / `python` → 创建或复用 `python_stt/.venv` 并装好 `faster-whisper`
> → 确保 `node_modules` → 执行 `npm run tauri dev`。首次会编译 Rust，需几分钟，之后窗口自动弹出。

## 2. 方式二：手动安装与启动

适合想看清每一步、或脚本在你的环境里报错的场景。

### 2.1 前置环境

| 软件 | 版本要求 | 用途 | 安装 |
|---|---|---|---|
| Node.js | 18+（建议 LTS） | 前端构建 | https://nodejs.org ，勾选 *Add to PATH* |
| Python | 3.10+ | STT 转写、音频探测/转码 | https://www.python.org ，勾选 *Add to PATH* |
| Rust | 1.77.2+（**MSVC** 工具链） | 后端编译 | https://rustup.rs |
| Visual Studio Build Tools 2022 | 含「C++ 桌面开发」 | 提供 MSVC 编译器 | 见下方命令 |
| WebView2 运行时 | 系统级 | Tauri 窗口内核 | Win10/11 一般已预装 |
| Git | 任意 | 拉取代码 | https://git-scm.com |

**C 工具链是必需项，也是最容易漏掉的一项。**
Tauri 的 Rust 侧最终要链接出 Windows 桌面程序，必须有 MSVC 或 MinGW 提供链接器与 C 运行时。
缺它时 `npm run tauri dev` **只会把前端跑起来（浏览器能打开）但不弹桌面窗口**，页面里所有数据库操作都会失败。

```powershell
# 推荐 MSVC（需管理员权限，会弹 UAC）
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --accept-package-agreements --accept-source-agreements --override "--wait --quiet --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

装完**重开终端**再启动项目。备选 MinGW-w64（体积更小）：

```powershell
winget install --id BrechtSanders.WinLibs.POSIX.UCRT
rustup default stable-x86_64-pc-windows-gnu   # 首次会全量重编译
```

安装 Rust 后确认用的是 MSVC 工具链：

```powershell
rustup default stable-msvc
```

> 选 Rust 时务必是 **MSVC**（`stable-msvc`）而非 GNU。GNU 工具链在 Windows 上经常因链接器/WebView2 头文件缺失而编译失败。

### 2.2 安装 Python 依赖（关键，容易漏）

`npm run tauri dev` **不会**自动安装 Python 依赖：

```powershell
cd F:\AI\sound_to_essay\python_stt
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

需要 `faster-whisper`（转写）；音频探测/转码需要 `soundfile` 或 `ffmpeg`/`ffprobe`（可选 `mutagen`）。
缺 ffmpeg/soundfile 时，转码走 PyAV 兜底（现有 faster-whisper 环境即可用）。

> 仓库通常已带 `python_stt/.venv`。换机器或删除后按上面重建即可。
> `requirements.txt` 只声明 `faster-whisper`，未锁定 `opencc`；繁→简转换在 `transcribe.py` 里有内置降级映射，没装 `opencc` 也能跑，只是覆盖面略小。

### 2.3 安装前端依赖

```powershell
cd F:\AI\sound_to_essay
npm install
```

### 2.4 启动

```powershell
npm run tauri dev
```

首次会自动：编译 Rust → 启动 Vite（绑定 `http://localhost:57123`）→ 弹出桌面窗口。
应用启动后自动加载上次打开的项目，无历史项目则显示空白工作区。

## 3. 首次运行：下载 Whisper 模型

转写需要本地 faster-whisper 模型。应用**不会**在录音时自动下载，请先在「设置」页：

1. 选择模型尺寸（如 `tiny` / `base` / `medium`，越小越快、越大越准）。
2. 确认模型保存目录（默认 `models/<模型名>/`）。
3. 点击下载，等待完成。

也可用环境变量指向已有模型：

- `WHISPER_MODEL_DIR`：模型根目录，或某个完整的 faster-whisper 模型目录。
- `WHISPER_DEVICE` / `WHISPER_COMPUTE_TYPE`：覆盖默认 `cpu` / `int8`（有 GPU 可改）。

> 国内网络：已默认走 `HF_ENDPOINT=https://hf-mirror.com` 镜像。若仍极慢，可手动从镜像站下载
> `Systran/faster-whisper-<size>` 的 CTranslate2 模型放到 `WHISPER_MODEL_DIR`。

## 6. 常见问题排查

| 现象 | 原因 / 解决 |
|---|---|
| **只有浏览器页面，没弹桌面窗口** | 缺 C 语言构建工具链，Rust 侧编译失败（终端会有 `linker link.exe not found` 或 `dlltool.exe not found`）。装好 MSVC 后重开终端再试。此时页面会显示「请在桌面应用中打开」的提示，而不是难懂的 `Cannot read properties of undefined`。 |
| 页面提示「无法加载资料库」/ 看不到历史数据 | 同上——浏览器环境没有 Tauri 运行时，读不到 SQLite。请用桌面应用打开。 |
| `无法加载文件 …start.ps1，因为在此系统上禁止运行脚本` | 用 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，或直接双击 `启动声文.bat`。 |
| `error: linker 'link.exe' not found` | 没装 VS Build Tools 的「C++ 桌面开发」，或 Rust 用的是 GNU 工具链。装好后 `rustup default stable-msvc`。 |
| 窗口起不来 / WebView2 相关报错 | 缺 WebView2 运行时，安装微软「WebView2 Evergreen Bootstrapper」。 |
| `找不到 transcribe.py` / `找不到 Python 环境` | Python 虚拟环境缺失或路径不对。重跑 `start.ps1`/`start.sh`，或按 §2.2 手动建 venv。 |
| 转写报「Whisper 模型不可用 / 无法下载」 | 未在设置页下载模型，或网络被墙。先下载模型；或配置 `WHISPER_MODEL_DIR`。 |
| 导入音频提示缺依赖 | 安装 `soundfile` 或 `ffmpeg`。 |
| 转写结果出现繁体字 | `opencc` 未安装，已走内置降级映射。如需完整转换：`pip install opencc-python-reimplemented`。 |
| `npm` / `cargo` 不在命令里 | 对应软件没装，或安装时没勾 *Add to PATH*。 |
| 首次编译卡很久 | 正常。Rust 首次构建要拉取并编译大量 crate，几分钟到十几分钟，之后有缓存会快很多。 |
| `cargo test` 报 link.exe not found | 需要 C 工具链；装好后即可。 |

## 7. 生产构建 / 打包

```powershell
cd F:\AI\sound_to_essay
npm run tauri build
```

产物位于 `src-tauri/target/release/bundle/`，含 `.exe`（NSIS 安装包）、`.msi` 与便携版。
构建同样需要 MSVC 工具链与 WebView2；`python_stt` 会作为资源（`resources/python_stt`）一起打进包。

**手机端独立构建**：

```powershell
node tools/build-mobile.mjs      # 或 npm run build:mobile
```

产物在 `dist-mobile/`，入口是 `mobile.html`。

## 8. 目录结构速览

```
sound_to_essay/
├─ 启动声文.bat / start.ps1 / start.sh   # 统一启动脚本
├─ 启动手机端HTTPS.bat                  # 手机端 HTTPS 调试服务

├─ src/                                  # React 前端（桌面端）
│  └─ mobile/                            # 手机记录端（独立入口 mobile.html）
├─ src-tauri/                            # Rust 后端
│  ├─ src/lib.rs                         # 命令注册（generate_handler!）
│  ├─ src/stt.rs                         # 调用 python_stt/transcribe.py
│  └─ tauri.conf.json                    # 构建/窗口/资源配置
├─ python_stt/                           # Python STT（faster-whisper）
├─ certs/                                # 本地自签证书（已 gitignore，不入库）
├─ models/                               # Whisper 模型（应用内下载）
├─ sounds/                               # 录音 WAV（原始素材，不自动删）
├─ data/                                 # oral_history.sqlite3 资料库
├─ docs/                                 # 文档（历史版本在 docs/archive/）
└─ tools/                                # 构建、验证、样例脚本
```
