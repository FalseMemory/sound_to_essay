# 手机端 HTTPS 调试说明

记录日期：2026-09-19
适用：C1 之后，需要在**手机真机**上测试「录音」功能时。

---

## 为什么必须要 HTTPS

浏览器只在**安全上下文**（`https://` 或 `localhost`）下暴露麦克风接口：

- 电脑用 `http://localhost:57123/mobile.html` 打开 → 是安全上下文 → **可以录音**
- 手机用 `http://192.168.x.x:57123/mobile.html` 打开 → **不是**安全上下文 →
  `navigator.mediaDevices` 直接不存在 → 录音不可用

这不是程序缺陷，也无法在页面里绕过。设置页与录音页会如实显示「当前页面不是安全上下文（未通过 HTTPS 访问）」。

---

## 一、一次性准备：生成证书并让手机信任

### 1. 生成证书（在电脑上执行）

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\make-dev-cert.ps1
```

脚本会：
- 首次运行时创建一个本地 CA（**只创建一次，之后一直复用**）
- 用该 CA 签发服务器证书，SAN 自动包含 `localhost`、`127.0.0.1` 和**当前局域网 IP**
- 把 CA 证书复制到 `public/sound-to-essay-ca.crt` 供手机下载

### 2. 启动桌面应用（提供 CA 下载通道）

双击 `启动声文.bat`。它会在 `http://<你的IP>:57123` 上提供 `public/` 里的文件。

### 3. 在 iPhone 上安装并信任 CA

1. 用 **Safari** 打开（必须是 Safari）：
   `http://<你的IP>:57123/sound-to-essay-ca.crt`
2. 提示「此网站正尝试下载配置描述文件」→ 点**允许**
3. 打开 **设置** → 顶部会出现「**已下载描述文件**」→ 点进去 → **安装**（需要输入锁屏密码）
4. 安装后到 **设置 → 通用 → 关于本机 → 证书信任设置** →
   找到 **Sound to Essay Local CA**，把开关**打开**

> 第 4 步不能省。只安装不信任的话，Safari 仍会认为证书无效，页面依然不是安全上下文。

Android 类似：下载 `.crt` → 设置里从存储安装 CA 证书（会提示"您的网络可能受到监控"，属正常）。

### 4. 启动 HTTPS 服务并访问

双击 `启动手机端HTTPS.bat`（或执行 `$env:VITE_HTTPS='1'; npm run dev`）。

看到 vite 输出的 `Network:` 那行后，用手机打开：

```
https://<你的IP>:57124/mobile.html
```

此时设置页的「安全上下文」应显示**正常**，录音按钮可用。

## 二、日常使用

| 服务 | 端口 | 命令 | 用途 |
| --- | --- | --- | --- |
| 桌面端 | 57123（http） | `启动声文.bat` | 桌面应用；同时提供 CA 下载 |
| 手机端 | 57124（https） | `启动手机端HTTPS.bat` | 手机录音调试 |

两个服务端口不同，**可以同时运行**，互不抢占。

- 只测界面/布局 → 桌面端即可，用手机访问 `http://<IP>:57123/mobile.html`
- 要测录音 → 必须启动 HTTPS 服务，用 `https://<IP>:57124/mobile.html`

## 三、IP 变了怎么办

局域网 IP 由路由器 DHCP 分配，**可能变化**（例如 192.168.31.189 → 192.168.31.191）。
IP 变化后证书 SAN 不再匹配，手机访问会再次报证书错误。

处理方式：**重跑证书脚本**即可（CA 不变，手机**无需**重新安装 CA）：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\make-dev-cert.ps1
```

然后重启 HTTPS 服务。

> 想一劳永逸？可以在路由器里为该网卡设置 **DHCP 地址保留**（静态 IP），IP 固定后就不必反复重签。

## 四、常见问题

**Q：手机打开 https 仍提示"此连接非私人连接"**
- CA 没安装，或安装了但没在「证书信任设置」里打开信任开关
- 或 IP 变了导致证书不匹配 → 重跑 `make-dev-cert.ps1`

**Q：录音页显示「当前页面不是安全上下文（未通过 HTTPS 访问）」**
- 当前用的是 `http://<IP>:57123`，换成 `https://<IP>:57124` 即可
- 用的是电脑 `localhost` 则不会有此问题

**Q：手机上录音点了没反应 / 提示权限被拒**
- 首次会弹麦克风权限询问，选"允许"
- 若之前误选了"不允许"：Safari → 网站设置 → 麦克风 → 允许

**Q：证书脚本报 `openssl 未找到`**
- 需要 Git for Windows（自带 openssl）。安装后重跑即可。

**Q：一定要装证书吗？**
- 如果只是**看看界面、检查布局**，不需要——`http` 就够，页面能正常打开。
- 只有**要在手机上真正录音**才需要 HTTPS。

## 五、安全说明

- `certs/` 下的私钥（`*.key`）已在 `.gitignore` 中排除，**不会提交到仓库**。
- 这个 CA 只用于本机局域网调试，与任何生产环境无关。
- 生产发布（阶段 E2）应使用正规证书与正式域名，**不要**分发这个调试 CA。
