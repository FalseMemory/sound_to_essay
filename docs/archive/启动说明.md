# 声文（sound_to_essay）启动说明

## 环境要求

- Windows 10/11
- Node.js ≥ 22（推荐用 WorkBuddy 托管的 `C:\Users\Administrator\.workbuddy\binaries\node\versions\22.22.2-3\node.exe`）
- Rust toolchain（rustup 安装）
- **C 语言构建工具链（必需，最容易漏掉的一项）**
  Tauri 的 Rust 侧最终要链接出一个 Windows 桌面程序，必须有 MSVC 或 MinGW 提供链接器与 C 运行时。
  **缺少它时 `npm run tauri dev` 只会把前端跑起来（浏览器能打开），但不会弹出桌面窗口**，页面里所有数据库操作都会失败。
  - 推荐 MSVC（Visual Studio Build Tools，管理员权限执行，会弹 UAC）：
    ```powershell
    winget install --id Microsoft.VisualStudio.2022.BuildTools -e --accept-package-agreements --accept-source-agreements --override "--wait --quiet --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
    ```
    装完请**重开终端**再启动项目。
  - 备选 MinGW-w64（体积更小）：
    ```powershell
    winget install --id BrechtSanders.WinLibs.POSIX.UCRT
    ```
    并让 Rust 使用 GNU 工具链：`rustup default stable-x86_64-pc-windows-gnu`（首次会全量重编译）。
- Python ≥ 3.10（用于 STT 与音频探测/转码）
- Python 依赖：`faster-whisper`（转写）、`soundfile` 或 `ffmpeg`/`ffprobe`（音频探测/转码）、`mutagen`（可选）

## 启动步骤

### 1. 安装前端依赖

```powershell
cd F:\AI\sound_to_essay
npx install
```

### 2. 准备 Python STT 环境

```powershell
cd F:\AI\sound_to_essay\python_stt
python -m venv .venv
.\.venv\Scripts\pip install faster-whisper soundfile mutagen
# ffmpeg/ffprobe 可选：若已加入 PATH 则优先使用；否则 soundfile 兜底
```

### 3. 启动开发模式

```powershell
cd F:\AI\sound_to_essay
npx tauri dev
```

这会同时启动 Vite 前端（默认 5173）和 Tauri 桌面窗口。

### 4. 生产构建

```powershell
cd F:\AI\sound_to_essay
npx vite build          # 前端构建到 dist/
# 桌面安装包需要 C 链接器；本机无法构建，需在装有 Visual Studio Build Tools 的机器上执行：
# npx tauri build
```

## 功能入口

| 功能 | 入口 |
| --- | --- |
| 录音 + 转写 | 创作区「录音」面板 |
| 资料库（记忆/章节/筛选） | 顶部导航「资料库」 |
| 导入音频（B1） | 资料库 → 章节模式 → 「导入音频」→ 选择文件 |
| 导入素材包（B3） | 资料库 → 章节模式 → 「导入素材包」→ 选择 .svpack |
| 备份 / 恢复（A3） | 资料库 → 章节模式 → 「备份与恢复」 |
| 设置（模型/LLM） | 顶部导航「设置」 |

## 数据位置

- 资料库 SQLite：`data/oral_history.sqlite3`
- 音频文件：`sounds/`
- Whisper 模型：`models/`（或设置中指定的目录）
- 创作区项目（.vse）：应用数据目录

## 测试样例

- 素材包样例：`tools/pack_samples/*.svpack`
- 生成/校验：`python tools/make_pack_samples.py` / `python tools/validate_pack_samples.py`

## 常见问题

- **只有浏览器页面，没有弹出桌面窗口**：缺少 C 语言构建工具链，Rust 侧编译失败（终端会有 `linker link.exe not found` 或 `dlltool.exe not found`）。按上方「C 语言构建工具链」安装后重开终端再试。此时浏览器里会显示一页「请在桌面应用中打开」的提示，而不是原来那句难懂的 `Cannot read properties of undefined`。
- **页面提示「无法加载资料库」/ 看不到历史数据**：同上——浏览器环境没有 Tauri 运行时，读不到 SQLite 资料库。请用桌面应用打开。
- **转写失败提示缺模型**：先在「设置」中下载 Whisper 模型。
- **导入音频提示缺依赖**：安装 `soundfile` 或 `ffmpeg`。
- **cargo test 报 link.exe not found**：需要 C 工具链；装好后即可执行。
