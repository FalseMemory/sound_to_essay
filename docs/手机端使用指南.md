# 手机端使用指南

> **面向使用者**（不是开发者）。要搭建/调试手机端服务请看 [`手机端HTTPS调试说明.md`](手机端HTTPS调试说明.md)。
>
> 对应计划 E2：「提供简短的 iPhone 使用与恢复指南」与「更换域名前必须提供资料迁出说明」。

---

## 一、这个手机网页是做什么的

它让你**用手机录口述**，再把素材带到电脑上的声文里整理成文章。

**资料存在哪里**：只存在**这台手机的浏览器里**（不进云、不上传、没有第三方统计）。
所以「清除网站数据」「换网址」「换手机」都会影响它——见第六、七节。

---

## 二、第一次使用（iPhone）

1. 用 **Safari** 打开给你的那个 HTTPS 网址（必须是 `https://` 开头，录音才可用）。
2. 点底部**分享按钮 → 添加到主屏幕**。以后从主屏幕图标进入，更像一个 App。
3. 首次会问**麦克风权限**，选「允许」。
4. 先试录 10 秒，确认能录、能存、能播。

> 建议先点一次设置页的**「申请保留本机资料」**，降低浏览器自动清理缓存把素材清掉的概率。
> 这不能替代导出备份，只是降低风险。

---

## 三、日常怎么用

底部有三个页签：**记录 / 我的素材 / 设置**。

### 记录
- 大圆按钮开始录音，再点一次结束并保存。
- 录音中有「暂停」「继续」「放弃」。
- 计时是真实录制时长；暂停期间不计入。
- **录音过程中每 1 秒就会落盘一次**，所以中途出意外也大多能救回来。

### 我的素材
| 想做什么 | 怎么做 |
| --- | --- |
| 改标题 / 补人物、地点、模糊时间、备注 | 点该条的**编辑** |
| 导入手机里已有的录音（语音备忘录、微信语音、录音笔文件等） | 点**「⬆ 导入音频」** |
| 不录音，只写一条文字 | 点**「＋ 写文字」** |
| 把素材发给电脑 | 点**「导出全部」**，或单条的**导出** |
| 播放 | 点右侧播放按钮 |

> **导入的音频不会在手机上转码。** 有些格式（如 `.amr`、`.wma`）手机浏览器放不了，
> 这时会明确提示「已导入但本机无法播放」——**文件是完整的**，导出到电脑后由电脑处理。

### 设置
- 申请保留本机资料、查看本机存储占用、切换主题。
- **诊断信息**：遇到问题时用来排查，只记数量和错误类别，**不含你口述的内容**。

---

## 四、把素材带到电脑

1. 手机「我的素材」→ **导出全部**（或单条导出）。
2. 系统分享面板里选**「存储到文件」**，存到「文件」App；或直接发给自己的微信/邮件。
3. 在电脑上打开**声文桌面版 → 资料库 → 章节模式 → 导入素材包**，选择那个 `.svpack` 文件。
4. 导入后检查条数和音频是否都在。

> **导出成功不会删除手机上的素材**，可以放心导出多次。
> **取消分享或导出失败都不会被算作"已导出"**。
> 另外：界面只会显示「已发起导出」，**它无法确认电脑是否真的收到了**——请到电脑上确认。

---

## 五、中断与恢复

录音可能被这些情况打断：**锁屏、切到别的 App、来电、刷新页面、关掉标签页、浏览器被系统回收**。

**回到记录页时，如果发现有没结束的录音，会显示一个恢复横幅**（开始时间、已保存分片数、大小），
你可以选择：

- **恢复并保存** —— 把已录到的部分合并成一条素材；
- **丢弃** —— 需要二次确认，丢弃后找不回来。

**关于恢复录音的两点如实说明：**

- 时长是**按分片数估算**的，不一定精确（分片本身不带时间戳）。
- 恢复出来的音频**建议先播放听一遍**，确认结尾是否完整。

如果提示「分片不连续」或恢复失败，**原分片会被保留**，不会静默丢弃。

## 六、⚠️ 什么情况会丢资料

| 情况 | 后果 | 怎么避免 |
| --- | --- | --- |
| **清除网站数据 / 浏览器"清除历史记录"里勾了网站数据** | **本机素材全部丢失，无法找回** | 定期导出素材包 |
| **换网址**（协议、主机名、端口任一不同） | 浏览器按"来源"隔离存储，**新地址看不到旧素材** | 换地址前先导出，见第七节 |
| **换手机 / 换浏览器** | 不自动同步 | 先导出再换 |
| 无痕（隐私）模式 | 关闭窗口即丢 | 别在无痕模式里用 |
| 手机存储空间不足 | 可能写入失败 | 保留足够空间，定期导出 |

**一句话：手机只是采集端，电脑才是保存的地方。录完尽早导出。**

## 七、换网址 / 换手机之前：把资料迁出

浏览器把数据按**「协议 + 域名 + 端口」**分隔存放。所以只要这三者之一变了（例如从 `https://192.168.1.5:57124` 换成 `https://192.168.1.9:57124`），
新地址就**看不到**旧地址的素材——**它们没有丢，只是被隔离在旧来源下**。

**迁移步骤（务必在换之前做完）：**

1. 回到**旧地址**打开手机端。
2. 到「我的素材」，确认条数与内容都在。
3. 点**「导出全部」**，把 `.svpack` 存到「文件」App（或发给自己）。
4. **在电脑上导入这个包并确认内容完整**——这是唯一可靠的备份。
5. 确认无误后，再切到新地址使用。新地址是空的，需要重新添加主屏幕图标。

> **不要**指望"换个地址资料还在"。也**不要**在没导出之前就清除网站数据。

---

## 八、遇到问题怎么办

1. 先到**设置 → 诊断信息**看看最近发生了什么（录音中断、保存失败、导入导出结果都会记）。
2. 需要反馈时点**复制**，把内容提供给开发者。
3. 录音相关问题可对照 [`安装与启动.md`](安装与启动.md) 的排查表；手机端服务相关看 [`手机端HTTPS调试说明.md`](手机端HTTPS调试说明.md)。

**录音无法启动时**，记录页顶部会直接说明真实原因（没走 HTTPS、权限被拒、设备被占用等）与对应解法，不会只显示"不支持"。

## 附：Android 说明

Android Chrome 上操作一致。差异：

- 录音格式通常是 **WebM/Opus**（iPhone 是 M4A），两者都能导出并在电脑端处理。
- 「添加到主屏幕」在 Chrome 菜单里，名称为「添加到主屏幕」或「安装应用」。
- 其余章节（导出、中断恢复、资料安全）同样适用。
